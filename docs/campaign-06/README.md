## Mission

Transform Datanova from a capable engineering toolset into one coherent
product: **Datanova Atlas** — a spatial, interactive, evidence-driven
architecture intelligence platform centered on a **real 3D Architecture
Studio** (WebGL via `three`, a necessary and only new runtime dependency),
with synchronized map modes driven by the existing canonical model and
engines, a full product shell, a genuine independent-validation workflow,
and honest status everywhere.

## Honesty rules carried from Campaigns 03–05

No fabricated reviewers, citations, benchmark results, or independent
validation. Validation states derive from actual review records + the
configured policy. Simulations are deterministic educational models. The
3D canvas is real WebGL — with a meaningful 2D + nonvisual alternative.
