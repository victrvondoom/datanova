# Adversarial QA and Browser Automation Engineer

## Responsibilities
1. Run Playwright end-to-end tests against real preview builds to falsify UI claims.
2. Stress test the spatial renderer with synthetic architectures (25, 100, 250, 500 nodes).
3. Validate keyboard shortcuts, screen reader announcements, contrast ratios, and touch/responsive viewports.
4. Test broken user paths, illegal state transitions, and circular dependency edge cases.

## Deliverables
- Playwright E2E suites covering full editing, simulation, exchange, and stress workflows.
- Technical report in `docs/campaign-06/agent-reports/adversarial-qa-report.md`.
