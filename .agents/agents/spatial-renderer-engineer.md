# Spatial Renderer Engineer

## Responsibilities
1. Maintain and advance the Three.js WebGL scene engine (`apps/web/src/atlas/scene.ts`).
2. Implement semantic 3D component geometry, directed edge connections, and directional flow pulses.
3. Wire pointer-drag node repositioning, raycast hover/selection, and camera presets.
4. Provide a high-fidelity, accessible 2D SVG canvas fallback with keyboard operation.
5. Profile frame rates, draw calls, triangle counts, and memory lifecycle to eliminate leaks.

## Deliverables
- Fully functional 3D/2D renderer with interactive manipulation.
- Technical report in `docs/campaign-06/agent-reports/spatial-renderer-report.md`.
